# Облачное хранилище «My Cloud»

[![CI/CD](https://github.com/DIvK-Neto/cloud-storage/actions/workflows/web.yml/badge.svg)](https://github.com/DIvK-Neto/cloud-storage/actions/workflows/web.yml)

[Демо приложения](https://DIvK-Neto.github.io/cloud-storage/)

![Скриншот приложения](docs/screenshots/screenshot.png)

Веб-приложение для управления файлами в облаке. Позволяет пользователям регистрироваться, загружать, скачивать, переименовывать и удалять файлы, создавать папки, делиться ссылками и оставлять комментарии.

## ✨ Основные возможности

- **Регистрация и вход** — с валидацией логина, email и пароля.
- **Личный кабинет** — просмотр и управление файлами и папками.
- **Загрузка файлов** — с указанием комментария, автоматическое сохранение на диске.
- **Управление файлами** — переименование, удаление, скачивание, перемещение между папками.
- **Управление папками** — создание, переименование, удаление, перемещение.
- **Специальные ссылки** — создание обезличенных ссылок для скачивания или просмотра файлов.
- **Комментарии гостей** — возможность оставлять комментарии к файлам без регистрации.
- **Административная панель** — управление пользователями (просмотр, удаление, изменение прав).
- **Логирование** — все действия записываются в консоль, файлы и базу данных.

## 🔄 Масштабируемость и разделение на репозитории

Проект спроектирован так, что бэкенд, фронтенд и документация могут быть вынесены в отдельные репозитории без изменения кода. Это позволяет разрабатывать и поддерживать части проекта независимо. Подробнее — в [docs/project-overview.md](docs/project-overview.md).
