## Бэкенд

| Технология            | Версия | Назначение                                            |
| --------------------- | ------ | ----------------------------------------------------- |
| Python                | 3.13   | Язык программирования для бэкенда                     |
| Django                | 6.0    | Веб-фреймворк для разработки бэкенда                  |
| Django REST Framework | 3.17   | Расширение для создания REST API                      |
| PostgreSQL            | 17     | Реляционная СУБД                                      |
| psycopg2-binary       | 2.9    | Драйвер для подключения Django к PostgreSQL           |
| django-cors-headers   | 4.9    | Обработка CORS-заголовков для кросс-доменных запросов |
| python-dotenv         | 1.2    | Загрузка переменных окружения из `.env`               |
| Pillow                | 12.3   | Обработка изображений (создание превью)               |

Все зависимости бэкенда перечислены в `backend/requirements.txt`.

## Инструменты и инфраструктура

| Технология     | Назначение                                              |
| -------------- | ------------------------------------------------------- |
| Git            | Система контроля версий                                 |
| GitHub         | Хостинг репозитория                                     |
| GitHub Actions | CI/CD для автоматического тестирования и деплоя         |
| ESLint         | Линтер для фронтенда (проверка качества кода)           |
| Prettier       | Форматтер для фронтенда (автоматическое форматирование) |
| nginx          | Веб-сервер для продакшена (прокси, статика)             |
| Gunicorn       | WSGI-сервер для запуска Django в продакшене             |
| Certbot        | Инструмент для получения SSL-сертификатов Let's Encrypt |

---

**Примечание:** Все версии библиотек актуальны на момент написания проекта и зафиксированы в `requirements.txt` и `package.json`. При развёртывании рекомендуется использовать указанные версии или более новые, совместимые с ними. Проект использует последние стабильные версии основных фреймворков и инструментов.
