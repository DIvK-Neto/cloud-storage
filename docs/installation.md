## Общие требования

Перед началом убедитесь, что на вашем компьютере установлены:

- **Python** 3.10 или выше
- **Node.js** 20 или выше
- **PostgreSQL** 15 или выше
- **Git**

Подробные инструкции по установке и настройке каждой части находятся в соответствующих файлах.

## Запуск проекта

После того как обе части установлены и настроены, запустите их:

**1. Бэкенд:** в папке `backend` выполните:


```bash
python manage.py runserver
```

Сервер запустится на `http://127.0.0.1:8000`. Если порт занят, можно указать другой, например:


```bash
python manage.py runserver 8001
```

**2. Фронтенд:** в папке `frontend` выполните:


```bash
npm run dev
```

Сервер запустится на `http://localhost:5173`.

Подробные команды и пояснения — в соответствующих файлах установки.

**Если сервер не запускается:**
- Убедитесь, что виртуальное окружение активировано (для бэкенда).
- Проверьте, что все зависимости установлены:

  для бэкенда:


```bash
pip install -r requirements.txt
```

  для фронтенда:


```bash
npm install
```

- Проверьте, что порты свободны (для бэкенда 8000, для фронтенда 5173).
- Для бэкенда: проверьте, что PostgreSQL запущен и база данных создана.
- Для фронтенда: проверьте, что Node.js установлен и `npm install` выполнялся без ошибок.

Если проблема не решается, обратитесь к детальным инструкциям в соответствующих файлах.
