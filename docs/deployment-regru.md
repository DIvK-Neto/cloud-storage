# Развёртывание на reg.ru

Этот документ содержит пошаговую инструкцию по развёртыванию проекта «Облачное хранилище My Cloud» на хостинге reg.ru (VPS / выделенный сервер). Он предназначен для разработчика, который хочет развернуть приложение в продакшене. Все команды выполняются на сервере под пользователем с правами sudo.

> **Примечание для новичков:** Все команды выполняются на сервере через SSH-подключение. Для редактирования файлов на сервере используйте `nano` (простой текстовый редактор) или `mc` (файловый менеджер). Если вы хотите править код локально, склонируйте репозиторий на свой компьютер, отредактируйте файлы в VS Code, сделайте коммит и отправьте изменения на GitHub, а затем выполните `git pull` на сервере.

## Регистрация аккаунта на reg.ru

Если у вас ещё нет аккаунта на reg.ru, выполните следующие шаги:

1. Откройте браузер и перейдите на сайт [reg.ru](https://www.reg.ru/).
2. В правом верхнем углу нажмите кнопку **«Войти»**.
3. В открывшемся окне нажмите ссылку **«Зарегистрироваться»**.
4. Заполните форму регистрации:
   - **Электронная почта** — укажите действующий email (на него придёт письмо с подтверждением).
   - **Пароль** — придумайте надёжный пароль (не менее 8 символов, с заглавными буквами, цифрами и спецсимволами).
   - **Повторите пароль** — введите пароль ещё раз.
   - **Согласие с условиями** — поставьте галочку, что вы согласны с условиями использования.
5. Нажмите кнопку **«Зарегистрироваться»**.
6. Перейдите в свою почту, найдите письмо от reg.ru и подтвердите регистрацию, перейдя по ссылке в письме.
7. После подтверждения войдите в [личный кабинет](https://www.reg.ru/user/authorize) с указанными email и паролем.

## Заказ VPS-сервера

После регистрации и входа в личный кабинет выполните следующие шаги:

1. В личном кабинете перейдите в раздел **«VPS и серверы»**.
2. Выберите **Linux VPS** (нам нужна операционная система Linux).
3. Настройте конфигурацию сервера:
   - **Операционная система:** выберите **Ubuntu 22.04 LTS** (рекомендуется) или **Debian 11**.
   - **Тариф:** выберите подходящий по характеристикам (минимум: 2 vCPU, 4 ГБ RAM, 50 ГБ SSD).
   - **Панель управления:** рекомендуется выбрать **ispmanager** — она упростит управление сервером.
   - **Срок оплаты:** выберите удобный для вас период (месяц, квартал, год).
4. Нажмите кнопку **«Заказать»**.
5. Оплатите счёт удобным для вас способом (банковская карта, электронные деньги и т.д.).
6. После оплаты услуга активируется в течение 10–15 минут. Сервер появится в списке ваших услуг в личном кабинете.

## Подключение к серверу по SSH

После активации VPS вы получите доступ к серверу. Для подключения используйте SSH.

### 1. Получите данные для подключения

В личном кабинете перейдите в раздел **«VPS и серверы»**, выберите созданный сервер. На странице управления вы увидите:
- **IP-адрес сервера** — например, `89.111.222.33`.
- **Имя пользователя** — по умолчанию `root`.
- **Пароль** — будет отправлен на email или отображаться в личном кабинете (сохраните его!).

### 2. Подключитесь к серверу

Откройте терминал на вашем компьютере (PowerShell на Windows, Terminal на macOS/Linux) и выполните команду:


```bash
ssh root@89.111.222.33
```

Замените `89.111.222.33` на реальный IP-адрес вашего сервера.

При первом подключении появится предупреждение о неизвестном хосте. Напишите `yes` и нажмите Enter.

Введите пароль, который вы получили от reg.ru (символы не отображаются при вводе).

Если всё сделано правильно, вы увидите приглашение командной строки, например:


```plaintext
root@your-server:~#
```

## Настройка PostgreSQL

Создайте базу данных и пользователя для проекта. Это нужно, чтобы Django мог подключаться к БД.


```bash
sudo -u postgres psql
```

В psql выполните:


```sql
CREATE DATABASE cloud_storage_db;
CREATE USER cloud_user WITH PASSWORD 'your_strong_password';
ALTER ROLE cloud_user SET client_encoding TO 'utf8';
ALTER ROLE cloud_user SET default_transaction_isolation TO 'read committed';
ALTER ROLE cloud_user SET timezone TO 'UTC';
GRANT ALL PRIVILEGES ON DATABASE cloud_storage_db TO cloud_user;
\q
```

## Настройка бэкенда

### Виртуальное окружение и зависимости

Создайте изолированное окружение Python и установите все зависимости проекта.


```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### Переменные окружения

Скопируйте шаблон `.env.example` и заполните его реальными значениями.


```bash
cp .env.example .env

```

Заполните:


```plaintext
SECRET_KEY=ваш_секретный_ключ
DB_NAME=cloud_storage_db
DB_USER=cloud_user
DB_PASSWORD=ваш_пароль
DB_HOST=localhost
DB_PORT=5432
DEBUG=False
```

## Настройка Gunicorn

Gunicorn — это сервер приложений, который будет запускать Django. Создайте systemd-сервис для управления им.


```bash
sudo nano /etc/systemd/system/cloud-storage.service
```

Вставьте:


```ini
[Unit]
Description=Cloud Storage Django App
After=network.target

[Service]
User=ваш_пользователь
Group=ваш_пользователь
WorkingDirectory=/var/www/cloud-storage/backend
ExecStart=/var/www/cloud-storage/backend/venv/bin/gunicorn --workers 3 --bind unix:/var/www/cloud-storage/backend/cloud-storage.sock cloud_storage.wsgi:application
Restart=always

[Install]
WantedBy=multi-user.target
```

Активируйте и запустите:


```bash
sudo systemctl daemon-reload
sudo systemctl enable cloud-storage
sudo systemctl start cloud-storage
```

## Настройка nginx

Настройте nginx для проксирования запросов к Gunicorn и отдачи статических файлов.


```bash
sudo nano /etc/nginx/sites-available/cloud-storage
```

Вставьте:


```nginx
server {
    listen 80;
    server_name ваш_домен_или_IP;

    location /static/ {
        alias /var/www/cloud-storage/backend/staticfiles/;
    }

    location /media/ {
        alias /var/www/cloud-storage/backend/media/;
    }

    location / {
        include proxy_params;
        proxy_pass http://unix:/var/www/cloud-storage/backend/cloud-storage.sock;
    }
}
```

Активируйте сайт и перезапустите nginx:


```bash
sudo ln -s /etc/nginx/sites-available/cloud-storage /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

## Настройка фронтенда через nginx (опционально)

Если вы хотите отдавать фронтенд через тот же nginx, добавьте соответствующий блок.


```nginx
location / {
    root /var/www/cloud-storage/frontend/dist;
    try_files $uri /index.html;
}
```

И измените `proxy_pass` на `/api/`:


```nginx
location /api/ {
    include proxy_params;
    proxy_pass http://unix:/var/www/cloud-storage/backend/cloud-storage.sock;
}
```

## Привязка домена к VPS

Чтобы ваш сайт был доступен по доменному имени, а не по IP-адресу, нужно привязать домен к VPS.

### Если домен зарегистрирован в reg.ru

1. В личном кабинете reg.ru перейдите в раздел **«Домены»** и выберите нужный домен.
2. На вкладке **«Управление»** в блоке **«DNS-серверы и управление зоной»** нажмите **«Изменить»**.
3. Пропишите DNS-серверы: `ns1.reg.ru` и `ns2.reg.ru`.
4. Добавьте **A-запись**, указывающую на IP-адрес вашего VPS-сервера:
   - **Имя:** `@` (или оставьте пустым для основного домена)
   - **Тип:** `A`
   - **Значение:** IP-адрес вашего сервера (например, `89.111.222.33`)
5. Добавьте ещё одну A-запись для поддомена `www`:
   - **Имя:** `www`
   - **Тип:** `A`
   - **Значение:** тот же IP-адрес сервера

### Если домен зарегистрирован у другого регистратора

1. В панели управления вашего регистратора найдите раздел управления DNS.
2. Пропишите DNS-серверы: `ns5.hosting.reg.ru` и `ns6.hosting.reg.ru`.
3. Добавьте A-записи для основного домена и поддомена `www`, указав IP-адрес вашего VPS-сервера.

**Важно:** После изменения DNS-записей может пройти от нескольких минут до 24 часов, пока изменения вступят в силу (период распространения DNS).

## Настройка SSL (обязательно)

Настройте SSL-сертификат для защиты соединений. Это обязательный шаг для продакшена.


```bash
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d ваш_домен -d www.ваш_домен
```

Следуйте инструкциям на экране. Certbot автоматически получит и установит бесплатный SSL-сертификат от Let's Encrypt, а также обновит конфигурацию nginx.
