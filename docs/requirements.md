## Операционная система

Проект разрабатывался и тестировался на:

- **Windows 10 / 11** (рекомендуется использовать PowerShell или WSL2)
- **macOS** (12 Monterey или новее)
- **Linux** (Ubuntu 22.04 LTS, Debian 11 или аналогичные)

## Проверка установленного ПО

Выполните в терминале следующие команды, чтобы убедиться, что всё установлено правильно:


```bash
python --version
node --version
psql --version
git --version
pip --version
npm --version
```

Пример ожидаемого вывода:


```plaintext
Python 3.13.2
v20.11.0
psql (PostgreSQL) 17.0
git version 2.45.1
pip 24.0
npm 10.5.2
```

Если какая-то команда не найдена, установите соответствующий компонент перед продолжением.

## Установка недостающих компонентов

### Установка Python

- Скачайте установщик с [python.org](https://www.python.org/downloads/)
- При установке обязательно отметьте опцию **«Add Python to PATH»**

### Установка Node.js

- Скачайте установщик с [nodejs.org](https://nodejs.org/) (рекомендуется LTS-версия)

### Установка PostgreSQL

- Скачайте установщик с [postgresql.org](https://www.postgresql.org/download/)
- Запомните пароль для пользователя `postgres` — он потребуется при настройке `.env`

### Установка Git

- Скачайте установщик с [git-scm.com](https://git-scm.com/downloads)

## Настройка переменных окружения (PATH)

После установки убедитесь, что пути к исполняемым файлам добавлены в переменную `PATH`. Это позволит запускать команды из любого терминала.

- Для Windows: проверьте через **Системные переменные** → **Path**
- Для macOS/Linux: выполните `echo $PATH` и убедитесь, что пути к `python`, `node`, `psql` присутствуют

---

**Примечание:** Все указанные версии были протестированы на момент написания проекта. Использование более новых версий допустимо, но может потребовать корректировки настроек. Рекомендуется использовать указанные версии для минимизации проблем.
