## Требования

Перед началом убедитесь, что на вашем компьютере установлены:

- **Python** 3.10 или выше (рекомендуется 3.13)
- **PostgreSQL** 15 или выше
- **Git**
- **pip** (менеджер пакетов Python)

Проверить версии можно командами:


```bash
python --version
psql --version
git --version
```

Если какой-то компонент отсутствует, установите его перед продолжением.

## Клонирование репозитория

Откройте терминал и перейдите в папку, где вы хотите разместить проект. Затем выполните:


```bash
git clone https://github.com/DIvK-Neto/cloud-storage.git
cd cloud-storage/backend
```

---

## Настройка виртуального окружения и зависимостей

Создайте виртуальное окружение:


```bash
python -m venv venv
```

Активируйте виртуальное окружение:

- **Windows (PowerShell):**
  
  ```powershell
  .\venv\Scripts\Activate.ps1
  ```

- **macOS/Linux:**
  
  ```bash
  source venv/bin/activate
  ```

После активации в начале строки терминала появится `(venv)`.

Установите зависимости:


```bash
pip install -r requirements.txt
```

---

## Настройка переменных окружения

Скопируйте шаблон `.env.example` в файл `.env`:


```bash
cp .env.example .env
```

Откройте `.env` в текстовом редакторе и заполните значения:


```plaintext
SECRET_KEY=ваш_секретный_ключ
DB_NAME=cloud_storage_db
DB_USER=postgres
DB_PASSWORD=ваш_пароль_базы_данных
DB_HOST=localhost
DB_PORT=5432
```

**Примечание:** Если у вас PostgreSQL настроен с пользователем `postgres` и паролем, укажите их. Для локальной разработки можно использовать `DB_USER=postgres` и пароль, который вы задавали при установке PostgreSQL.

## Настройка PostgreSQL (локально)

Убедитесь, что PostgreSQL запущен. Создайте базу данных для проекта:

- **Windows:** откройте командную строку и выполните:
  
  ```bash
  psql -U postgres
  ```
  Затем в psql:
  
  ```sql
  CREATE DATABASE cloud_storage_db;
  \q
  ```

- **macOS/Linux:** выполните:
  
  ```bash
  sudo -u postgres psql
  ```
  Затем в psql:
  
  ```sql
  CREATE DATABASE cloud_storage_db;
  \q
  ```

Если вы используете другой способ управления PostgreSQL, создайте базу данных с именем `cloud_storage_db`.

## Применение миграций и создание суперпользователя

Примените миграции:


```bash
python manage.py migrate
```

Создайте суперпользователя для входа в админку:


```bash
python manage.py createsuperuser
```

Следуйте инструкциям (введите логин, email, пароль).

---

## Запуск сервера разработки

Запустите сервер разработки Django:


```bash
python manage.py runserver
```

Сервер будет доступен по адресу `http://127.0.0.1:8000`.

---

## Проверка работоспособности

1. Откройте браузер и перейдите на `http://127.0.0.1:8000/admin`.
2. Войдите в админку под созданным суперпользователем.
3. Проверьте, что разделы `Accounts app` и `Files app` видны.
4. Если админка открывается и модели отображаются — бэкенд установлен корректно.

## Часто возникающие проблемы

### Ошибка: `ModuleNotFoundError: No module named 'psycopg2'`

Установите драйвер PostgreSQL:


```bash
pip install psycopg2-binary
```

### Ошибка: `FATAL: role "postgres" does not exist`

Измените `DB_USER` в `.env` на существующего пользователя PostgreSQL или создайте пользователя `postgres` с паролем.

### Ошибка: `psql: command not found`

PostgreSQL не установлен или не добавлен в `PATH`. Установите PostgreSQL и добавьте его в переменные окружения.

### Ошибка: `address already in use`

Порт 8000 занят другим приложением. Остановите его или измените порт в настройках (добавьте `--port=8001` к команде `runserver`).
